#### QUÉ ES DEPAFIX
Sistema multi-dominio de automatización para pymes chilenas. Tres verticales operativas:
1. TRADING CRIPTO  — bot Kraken + Supabase (paper trading)
2. CONSTRUCCIÓN    — SERVIU / obras / presupuestos / caja
3. LEGAL           — Procurador (trámites judiciales)
Y una capa transversal: CEO INFORMÁTICO — monitorea los 3 dominios vía workers, detecta fallos, diagnostica con LLM (Anthropic) y actúa con whitelist. Corre en Railway, escribe a Supabase.
VISIÓN 2026: extender a un 4to vertical — AGENCIA DE PUBLICIDAD (costos $0 al inicio, servicios de conocimiento: auditoría, copy, reportes de ads).

### ================================================================ ARQUITECTURA TÉCNICA
Stack:
* Python 3.11+, FastAPI, Pydantic v2
* Supabase (Postgres + PostgREST) como DB y API
* Railway para workers (1 contenedor, ~$5/mes)
* Vostro local (Ubuntu) para bot trading systemd
* Anthropic LLM: haiku-4-5 ($0.001/llamada) y sonnet-4-6
* Presupuesto LLM: cap $2/día, cache por contexto_hash 2h

Flujo CEO Informático: sensores → ceo_health → rules_engine (8 reglas) → si fail → diagnosticar_fallo (LLM) → actuator (5 acciones whitelisted, dry_run) → ceo_actions (audit trail inmutable) → predictor (patrones proactivos) → ceo_predictions → reporter_daily (08:00 UTC) → Telegram → watchdog externo (Vostro cada 5 min)
